LIMITATIONS

Introduction

The creation of a schematic involves a lot of complex entities and different CAD packages may support different features or handle objects and connectivity in slightly different ways. As such, there are limitations to any import process.

Known limitations are outlined below but please do contact us if you are having problems.

Limitations

  • Currently only supports OrCAD v9.2 and OrCAD 17.2 EDIF2 file format.
  • Bitmaps (e.g. logos) are not present in the EDIF file so will not be imported.
  • Non standard pin-name or pin number font sizing will be ignored; the importer assumes a standard 100th spacing for device pins.
  • Module components (as opposed to drawn sub-circuits) are not currently supported.
  • Hierarchical designs with sibling children are treated as carrying hierarchical naming; design global annotation data (e.g. U3:A on sibling 1 and U3:B on sibling 2) is not present in the EDIF file and thus cannot be preserved.
  • Hierarchical designs where a child module has more than one sheet cannot be imported since this is not currently supported in Proteus.
  • Power nets are treated as global unless this is changed manually on the ‘Edit Design Properties’ dialogue. This may lead to the netlist comparison reporting extra connections since the EDIF format cannot represent global power nets. The wiring of power nets in hierarchical designs should be checked very carefully to ensure that the imported design matches the original design intentions.
